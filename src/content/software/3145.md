설치 파일과 크기는 BDCAMSETUP-KOR.exe(28.6MB)와 같으며 내컴퓨터의 다운로드 폴더에 저장됩니다.

### 반디캠 다운로드 및 무료 설치

다운로드한 설치 파일을 실행하면 안내에 따라 간편하게 설치가 진행됩니다.

![반디캠-무료-설치시-주의사항](/uploads/2025/07/반디캠-무료-설치08-1024x444.webp)

> 설치 시, ‘Microsoft에서 확인된 앱이 아닙니다.’라는 메시지가 뜨면,  
> ‘내 앱 권장 사항 설정 변경’ 클릭 -> ‘제한 없음’을 선택한 후, 다시 설치하여 주시기 바랍니다.

1.  반디캠 프로그램을 다운로드 받은 후, 설치 프로그램(BDCAMSETUP\_KOR.EXE)을 실행합니다.
2.  반디캠 설치창에서, \[다음\] 버튼을 클릭합니다.
3.  소프트웨어 최종 사용자 사용권 계약서입니다. 내용에 동의하시면 \[동의함\]을 선택합니다.
4.  프로그램 설치 구성요소를 선택한 후, \[다음\] 버튼을 클릭합니다.
5.  프로그램이 설치될 위치(폴더)를 선택한 후, \[설치\] 버튼을 클릭하면 프로그램 설치가 진행됩니다.
6.  반디캠 설치가 완료되면 \[마침\] 버튼을 클릭하면 프로그램 설치가 종료됩니다.

프로그램 설치 중, “다음 파일을 열 수 없습니다.” 혹은 “반디캠 프로그램이 실행중입니다.”와 같은 에러메시지가 보일 경우, “작업 관리자 – 세부 정보”에서, “bdcam.exe” 프로세스를 종료한 후 다시 시도해 봅니다.

### F12 개발자 도구 사용하기

F12 키를 눌러 크롬 개발자 도구를 열면 별도 프로그램 없이 동영상을 다운로드할 수 있습니다.

다만 잘못 조작하면 컴퓨터에 문제가 생길 수 있으니 주의해야 합니다.

![F12 개발자 도구 사용하기](https://blog.kakaocdn.net/dn/kQaop/btsHLW8fBln/FbA3EaNlIfcxk1qvsz1JBk/img.webp)

1.  크롬에서 원하는 영상 열기
2.  F12로 개발자 도구 열기
3.  Network 탭에서 Media 속성 클릭
    *   이미 영상을 재생했다면 F5로 새로고침
    *   재생 전이라면 Media 클릭 후 재생
    *   광고가 있다면 광고 끝난 후 Media 클릭
4.  mp4 파일 중 원하는 영상 찾기
5.  해당 파일 우클릭 후 ‘새 탭에서 열기’로 확인
6.  메뉴에서 ‘다운로드’ 클릭

이렇게 하면 개발자 도구를 통해 스트리밍 동영상을 자유롭게 저장할 수 있습니다. 단, 불법 다운로드는 주의해야겠죠.

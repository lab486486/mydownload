## 크롬 웹스토어 다운로드 방법(Chrome Download)

크롬 웹 스토어에서는 웹 브라우저의 확장프로그램을 추가해서 원하는 기능을 보강할 수 있습니다.

광고 제거부터 번역 기능까지 웹스토어에서 다운로드하는 방법에 대해 알아보도록 하겠습니다.

### 크롬 웹스토어 접속 방법

1.  직접 주소를 입력해서 크롬 웹스토어로 이동
2.  확장프로그램 관리 메뉴에서 크롬 웹스토어로 이동

![크롬 웹스토어 다운로드 확장프로그램 관리 메뉴](https://blog.kakaocdn.net/dn/vPi2j/btrKF78WDnZ/KdBpAgqVBTJmsWYU5yckg0/img.png)

크롬 웹스토어 다운로드 확장프로그램 관리 메뉴

[크롬 웹스토어 다운로드](https://chrome.google.com/webstore/category/extensions)

[윈도우PC 다운로드](https://chrome.google.com/webstore/category/extensions) [Mac 다운로드](https://chrome.google.com/webstore/category/extensions)

크롬 웹스토어 다운로드에 앞서 먼저 해야할 일은 크롬 웹스토어에 접속하는 방법을 알고 있어야 합니다.

크롬 웹스토어에 접속하는 방법은 크게 2가지입니다. 직접 주소를 입력하거나 메뉴를 이용해서 이동하는 방법입니다.

크롬 웹스토어 주소는 [https://chrome.google.com/webstore/category/extensions](https://chrome.google.com/webstore/category/extensions)입니다.

이 주소를 클릭해서 즐겨찾기 추가를 하거나 크롬을 실행해서 오른쪽 상단에 퍼즐 아이콘을 누르고 ⚙️확장프로그램 관리를 눌러줍니다.(사진▼참고)

![크롬 웹 스토어 열기](https://blog.kakaocdn.net/dn/lZd0f/btrKHa4U3Y5/pv22D089VD7JNFQG7yojF1/img.png)

확장프로그램 관리 > Chrome 웹 스토어 열기 > 크롬 웹스토어 접속

주소를 추가해두거나 크롬 웹스토어에 접속하는 방법 중 한개는 꼭 기억해두고 사용하시길 추천드립니다.

### 크롬 웹스토어 다운로드 방법

1.  크롬 웹스토어에 접속해서 원하는 기능 검색
2.  검색결과에서 확장프로그램 선택
3.  Chrome에 추가 버튼 클릭
4.  크롬 웹스토어 다운로드 완료

![크롬 웹스토어 접속화면](https://blog.kakaocdn.net/dn/bdAwoJ/btrKF0WeTg7/KdL7KfACeaQI05jQzX7utk/img.png)

크롬 웹스토어 접속 > Chrome 추가 > 확장프로그램 다운로드

크롬 웹스토어에 접속했다면 왼쪽 검색창에 확장프로그램을 검색합니다. 예를들어 번역 기능을 추가하고 싶다면 검색창에 번역이라고 입력하고 엔터를 눌러줍니다.

![Chrome 추가 화면](https://blog.kakaocdn.net/dn/bRSjPm/btrKFTiPiK2/0nEtQWvCPMTuWki9261gsK/img.png)

그러면 여러 확장프로그램이 나오는데 구글(Google) 번역 확장프로그램을 추가해보도록 하겠습니다.

Google 번역을 누르면 다운로드 페이지로 이동하는데 다운로드 방법은 Chrome추가(파란색 버튼)을 누르면 됩니다.

![확장프로그램 설치 전 확인메시지](https://blog.kakaocdn.net/dn/p4Snv/btrKGp2ALLJ/EBckqN4Kqskd8EEpwlfz10/img.png)

Chrome 확장프로그램 설치 전 확인 메세지

Chrome 추가버튼을 누르게 되면 Google 번역을(를) 추가하시겠습니까?라는 확인창이 나옵니다.

앱의 권한을 묻는 확인창이 나오는데 여기서 확장 프로그램 추가를 누르면 설치가 진행됩니다.

설치 이후에는 확장프로그램 아이콘(퍼즐모양)을 누르면 Google번역이 추가된 모습을 확인할 수 있는데요!

오른쪽에 있는 점3개 버튼을 누르면 확장프로그램(실행), 옵션, 삭제 등의 메뉴를 선택할 수 있습니다.

### 확장프로그램 설치 후 메뉴 사용 및 고정 방법

그리고 크롬 웹 브라우저에서 바로 실행하고 싶다면 고정 기능을 활용해서 확장 프로그램을 표시할 수 있는데요!

📌핀셋 아이콘을 누르면 고정 기능이 활성화되면서 간편하게 사용할 수 있습니다.

![확장프로그램 삭제하는 방법 중 하나인 웹스토어 접속하여 삭제](https://blog.kakaocdn.net/dn/bM6J4A/btrKJ6f9Wlm/7YyHy4i3U2sElHvoXWVvFK/img.png)

확장프로그램 삭제하는 방법 중 하나인 웹스토어 접속하여 삭제

[Chrome 웹 스토어 바로가기](https://chrome.google.com/webstore/category/extensions "Chrome 웹 스토어 바로가기")

설치한 확장프로그램을 삭제 방법은 다시 웹스토어에 접속하거나 확장프로그램 관리 메뉴에서 점3개 버튼을 누릅니다.

그리고 Chrome에서 삭제 메뉴로 들어가서 삭제하면 보다 쾌적하게 크롬 확장프로그램 사용이 가능합니다.

이상으로 크롬 웹스토어 다운로드 방법을 비롯해서 접속, 삭제 방법까지 함께 알아봤습니다.

웹 브라우저에 다양한 기능을 추가해서 편리하고 빠른 작업이 되셨으면 좋겠습니다. 감사합니다.

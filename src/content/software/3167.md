### 컴퓨터 자동 예약 종료 프로그램 사용법

오토오프 4.25버전을 다운로드 받았다면 더블클릭하여 실행하면 바로 컴퓨터 자동 종료 및 예약이 가능한데 프로그램 탭(메뉴) 별 사용법을 알려드릴께요!

예약 탭에서는 반복 예약 버튼을 클릭하면 원하는 기능을 반복해서 실행하도록 할 수 있고, 여러 개의 작업을 동시에 예약할 수 있습니다.

상태 탭에서는 오늘 사용시간, 실행 횟수 등의 프로그램 사용 상태를 확인할 수 있습니다.

옵션 탭에서는 추가 옵션 사항들에 대한 내용으로 알람 소리 등 원하는 소리로 설정하고, 프로세스를 강제로 종료할 수 있습니다.

그리고 비밀번호 잠금 기능으로 예약 변경, 프로그램 종료를 금지할 수 있고, 시스템 트레이 메뉴에서도 컴퓨터 자동 예약 종료 프로그램 기능을 바로 실행할 수 있습니다.

### 오토오프 설치 및 주요 기능

설치 완료 후 작업 표시줄에 아이콘이 생성되며, 마우스 우클릭으로 다양한 예약 작업을 즉시 실행하거나 설정할 수 있습니다.

간편한 옵션으로 원하는 시간에 시스템 종료, 다시 시작, 재우기, 최대 절전 모드, 화면 끄기/켜기, 화면 보호기 실행, 컴퓨터 잠금, 알람, 프로그램 실행/종료를 할 수 있습니다.

원하는 날짜와 시각에 컴퓨터 종료, 재시작, 절전, 화면 끄기 등을 예약할 수 있고, 비밀번호 잠금 설정으로 프로그램 사용을 제어할 수도 있습니다.

Windows XP SP3 이상, 7, 8, 10, 11 32비트 및 64비트를 모두 지원합니다.

**Q. 설치 시 제휴 프로그램 동의 항목이 보이는데 선택하지 않아도 되나요?**  
네, 설치 중 제휴 프로그램 항목은 원하지 않으면 체크 해제해서 설치 가능하며 프로그램 기능과 무관합니다.

**Q. 예약 시간이 되지 않았는데 컴퓨터가 자동 종료되나요?**  
예약 설정이 정확하게 되었는지 확인하세요. 오토오프는 예약된 시간에만 작동합니다.

**Q. 컴퓨터 자동 예약 종료 프로그램은 다수의 예약 작업을 설정할 수 있나요?**  
네, 다중 예약 기능을 통해 여러 예약 동작을 동시에 관리할 수 있습니다.

오토오프를 활용하면 컴퓨터 전원을 효율적으로 관리하고 전기세 절감, 보안 강화에 큰 도움이 될거라 생각합니다.

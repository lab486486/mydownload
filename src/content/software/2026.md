## 개인사업자를 위한 무료 회계 다운로드 프로그램

회계 관리는 모든 사업체에서 필수적인 업무입니다. 하지만 높은 비용의 유료 프로그램을 구매하기 부담스러운 개인사업자나 소규모 업체들도 많이 있습니다.

이런 분들에게 추천할만한 무료 회계프로그램이 있습니다. 바로 ‘알찬장부’ 회계 프로그램입니다.

### 알찬회계 주요 특징

1.  완전 무료 프로그램
    *   기간 제한이나 기능 제한 없이 100% 무료로 제공됩니다.
    *   단, 별도 유료 기능을 사용하려면 결제가 필요합니다.
2.  직관적이고 사용하기 쉬운 UI
    *   은행식 전표 입력, 자동 분개 등 편리한 기능 제공
    *   초보자도 쉽게 배우고 활용할 수 있는 인터페이스
3.  필수 회계 기능 모두 지원
    *   전표 입력, 원장 조회, 재무제표 출력 등 기본 기능 완비
    *   일반 회계업무에 필요한 대부분의 기능 무료 제공

### 알찬장부 주요 회계 기능

#### 1\. 전표 입력

*   쉬운 은행식 입출금 전표 입력
*   매입/매출 자동분개 기능
*   반복 거래 입력 기능

#### 2\. 원장 조회

*   집계식 조회 화면으로 입력과 조회 동시에 가능
*   거래처별 매입/매출 내역 및 미수/미지급금 현황 조회
*   계정별 합계 및 상세 원장 조회

#### 3\. 재무제표 출력

*   종이 출력용 분개장, 손익계산서, 대차대조표 제공

### 알찬회계 다운로드 및 설치 방법

2.  홈페이지 중앙의 ‘무료 다운로드’ 버튼 클릭
3.  설치 파일 다운로드 및 실행
4.  설치 마법사에 따라 설치 진행

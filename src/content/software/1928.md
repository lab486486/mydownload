#### 한컴오피스 2018 한글

개방형 문서 포맷 hwpx 문서 지원, 국가표준 개방형 문서포맷이 기본 문서 형식이 됩니다.

이제 편리하게 한글에서 데이터를 추출하고, 고대비 모드를 활용해서 문서의 가독성을 높여보세요!

더 쉬운 협업이 필요한 사람들의 표준 문서 프로그램으로써 가장 편리한 한글이 더욱 편리하게 느껴집니다.

원하는 정보에 태그를 더해 더 쉽고 분류하고 찾으면 동료들과 손쉬운 협업을 할 수 있어집니다.

#### 한컴오피스 2018 한셀

지금 시대의 가장 큰 화두는 데이터입니다. 한셀은 모두가 더 쉽고 편리하게 데이터를 다룰 수 있게 만들었습니다.

더욱 많아진 한셀의 함수를 포함해서 직관적인 유저 인터페이스로 쉽게 데이터 작업이 가능합니다.

셀 서로 바꾸기, 인스턴트 필터 등의 기능은 더 쉽게 배울 수 있도록 더 간단히 원하는 작업을 할 수 있도록 도와줍니다.

또한, 길고 복잡한 수식을 보다 더 편하게 입력하기 위해 수식 입력 줄 기능을 강화했습니다.

![한컴오피스 한셀 소개](https://blog.kakaocdn.net/dn/bcNOHi/btrMyiNkdSS/vRnbD8OTiWk4M9D9oR7NA1/img.webp)

#### 한글오피스 2018 한쇼

내 마음대로 움직여도 눌러지지 않는 도형들, 눌러도 선택되지 않는 텍스트까지 사용자를 고려한 개선된 UX와 작업을 돕는 세심한 개선까지 한쇼가 발전되어 돌아왔습니다.

회전하는 개체의 각도를 고려해서 동적으로 변경됩니다.

뿐만 아니라 애니메이션 복사 기능이 추가되어 보다 편리한 편집과 효과적인 프레젠테이션을 위해 강화된 스마트 애니메이션 기능을 활용할 수 있습니다.

한쇼 데이터 활용을 ㄹ위한 문서 추출 확장자가 추가되어 txt로 추출하여 많은 문서를 활용할 수 있습니다.

#### 한글오피스 2018 한워드

한 워드는 워드와 한글의 장점을 모두 가진 워드프로세서입니다.

어떤 워드포르세서르르 사용해야 할지 고민이라면 사용성과 안정성 모두를 잡은 한 워드를 사용하는 것이 바람직하겠습니다.

장점을 모두 가진 워드 프로세서답게 수식이 자유롭고, 호환성을 위해 수식 입력 방식도 개선되었습니다.

이제 여러 개의 수식을 하나로 합치거나 텍스트와 수식을 함께 선택할 수도 있습니다. 복잡한 수식도 즉시 작성하여 추가할 수 있습니다.

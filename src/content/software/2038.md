아래에서 한글2020 다운로드와 무료 설치 하는법에 대해 함께 알아보도록 하겠습니다.

## 한글2020 다운로드 사이트

> ▶️ 한글과컴퓨터 홈페이지 > 다운로드 센터 > 한글2020 체험판 다운로드

한글2020 프로그램을 다운로드 하는 방법은 한글과컴퓨터 공식 홈페이지를 통해 가능합니다.

현재 다운로드 센터로 접속하면 링크는 사라졌지만, 서버 상에 파일은 남아있어서 아래의 주소를 통해 다운로드가 가능합니다.

### 한글2020 설치 기본사양

한글2020 설치하는 시간은 인터넷 연결 속도에 따라 다르며, 최상의 다운로드 환경을 위해서는 광대역 인터넷 연결을 사용하는 것이 좋습니다.

설치 기본사양은 최근 출시된 컴퓨터의 경우 대부분 실행 가능한 수준입니다.

## 한글2020 무료 설치 하는법

한글2020 설치파일(Hancom\_Office\_2020\_Trial.exe) 파일을 다운로드 폴더에서 더블 클릭합니다.

한컴오피스 설치 전에 NET Framework 4.8 프로그램이 설치되는데요! 이 프로그램이 반드시 설치되어야 한글2020 사용이 가능합니다.

한글2020의 경우 ISO 표준인 ODF를 지원하기 때문에 이 프로그램 설치가 필수입니다.

![한글2020 Visual C++ 무료 설치](https://blog.kakaocdn.net/dn/XQUIB/btsHnKhFril/KhG49IlJhHjhZMA2FsaJ2K/img.png)

확인 버튼을 누르게 되면 Visual C++ 2015-2019 Redistributable 프로그램이 설치되고, 이어서 한글2020 설치가 진행됩니다.

한글2020 설치가 진행되면 먼저 사용권 계약서 동의를 하게 되고, 이어서 프로그램 설치가 시작됩니다.

![한글2020 Redistributable 무료 설치](https://blog.kakaocdn.net/dn/bMlf20/btsHnqRijRy/hL1KTTZU2KSnCBjcC78wrK/img.png)![한글2020 사용권 계약 동의함](https://blog.kakaocdn.net/dn/d2N80C/btsHnJb2kFA/9JSDjZQA75ZycKXU5ukdJk/img.png)

설치가 종료되면 한글과컴퓨터에서는 개방형 문서 형식인 HWPX를 사용할 것을 권장한다는 메세지와 함께 한글 2020에서 사용할 기본 파일 형식을 선택해야 하는데 한글 표준 문서(\*.hwpx)를 선택하고 설정 버튼을 누르면 됩니다.

![한컴오피스2020 설치 화면](https://blog.kakaocdn.net/dn/Cgpsa/btsHo7XqcVH/6hh56owWB8rX6dwFO3nhGk/img.png)![한글2020 무료 설치 완료](https://blog.kakaocdn.net/dn/n7Ejo/btsHnsaveDh/NAKoJhSCPVKQgla4WSPsSk/img.png)

이렇게 설치가 완료되면 바탕화면의 한글2020 아이콘을 더블 클릭하여 사용할 수 있습니다.

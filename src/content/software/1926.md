## 알캡처 무료 다운로드와 단축키 총정리

컴퓨터를 사용하다보면 현재 화면을 저장하여 누군가에게 전달하거나 문서에 포함시켜야할 때가 있는데요!

다양한 캡쳐 기능이 포함된 알캡쳐를 홈페이지에서 다운로드받기 해서 손쉽게 컴퓨터 화면을 활용할 수 있습니다.

### 알캡쳐 다운로드 받는 방법

1\. 알툴스(ALTools) 홈페이지 접속

2\. 다운로드 > 알캡처 클릭

3\. 알캡처 3.04 설치하기 버튼 클릭

### 알캡처 단축키 총정리

알캡쳐를 사용하는 이유 중 하나가 바로 단축키를 이용한 화면캡쳐입니다. 그만큼 편리하고 다른 캡쳐프로그램에서 볼 수 없는 편의성을 제공하는데요!

특히 단축키는 사용자가 직접 정할 수 있어서 가장 좋은 것 같습니다.

기본값 : Print Screen 키 사용 (활성화 시) Print Screen 키를 직접 지정 캡쳐 기능으로 사용

직접지정

Ctrl + Shift + C

창 캡쳐

Ctrl + Shift + W

단위영역

Ctrl + Shift + D

전체캡처

Ctrl + Shift + A

스크린캡처

Ctrl + Shift + S

지정사이즈

Ctrl + Shift + F

위 표에 입력된 값들은 알캡쳐 단축키(기본값)로 환경설정 > 단축키설정에서 사용자가 직접 수정할 수 있습니다.

윈도우키와 Alt(알트)키를 추가해서 더욱 효과적으로 설정할 수 있으며, 알파벳 키도 수정 가능합니다.

### 알캡쳐 3.0 신규 기능 정보

#### 1\. 자르기 도구

캡처한 결과물에서 특정 부분만 잘라서 사용하고 싶을 때 자르기 도구로 필요 없는 부분을 제거하고 원하는 결과물을 편집가능

#### 2\. 모자이크 도구

캡처한 결과물에 개인정보나 가리고 싶은 부분에 모자이크 도구를 이용해 민감한 정보를 가릴 수 있음

#### 3\. 형광펜 도구

텍스트가 많은 기사나 문서를 캡처해 전달할 때 형광펜 도구로 특정 텍스트를 강조할 수 있음

#### 4\. 텍스트 입력 도구

캡처 이미지와 함께 전달하고 싶은 메세지가 있을 때 별도의 툴 없이 텍스트 입력 도구로 간단하게 작성 가능

#### 5\. 이미지 선택 모드

최근 캡처 목록에서 일부 이미지만 골라낼수 있는 선택모드는 필요한 이미지만 저장하거나 필요없는 이미지 삭제 가능

#### 6\. 실행창/결과창 인터페이스 개선

캡처 모드 및 편집 도구 등의 기능 명칭과 아이콘을 직관적으로 개선하고 캡처 사용 환경을 방해하지 않도록 UI 간소화

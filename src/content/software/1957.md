## 알집 무료다운로드 방법

압축 프로그램 중에 가장 사용자가 많은 프로그램이 바로 알집(ALZip)입니다.

반디집, 밤톨이 등 압축프로그램들이 있지만, 알집만큼 빠른 속도와 편리한 인터페이스를 가진 프로그램도 드문 것 같습니다.

아래에서 알집 무료 다운로드 방법에 대해 알아보도록 하겠습니다.

링크를 클릭하면 알집 공식 다운로드 사이트로 이동하며 설치하기 버튼을 클릭하면 파일이 다운로드 폴더에 저장됩니다.

알집 무료 다운로드 후에는 실행 버튼을 누를 경우 즉시 프로그램 설치가 진행되는데 알툴즈라는 패키지 형태로 설치가 진행됩니다.

알집 외에도 알씨(ALSee), 알약(ALYac) 등 다양한 이스트소프트의 알 시리즈를 동시에 설치할 수도 있습니다.

최신의 컴퓨터 또는 노트북이라면 알집을 작동시키는데 큰 문제는 없지만 출시된 지 5~10년 된 컴퓨터의 경우 램을 업그레이드하는 것을 권장합니다.

### 2\. 알집 설치 방법

1) \[설치시작\] 버튼 클릭

2) 빠른설치 아래 \[사용자 지정\] 클릭

3) 제휴추가 및 zum을 검색엔진으로 체크 해제

4) 설치 버튼 클릭

5) 완료 후 아래에 00을 설치해 보겠습니까? 체크 해제

내 컴퓨터의 다운로드 폴더에 알집 설치 프로그램이 저장되었다면 올바르게 저장되었는지 확인을 합니다.

간혹 인터넷 접속환경이 불안정하여 24.5MB 보다 파일이 작은 상태에서 완료가 되는 경우가 있는데요!

이럴 경우 설치를 진행하다가 중간에 오류가 발생할 수 있으니 설치 파일의 용량을 확인하는 습관도 중요합니다.

그러니 조금 귀찮더라도 화면을 주시하면서 불필요한 부분의 체크박스를 헤제하시기 바랍니다.

설치가 완료된 이후에도 제휴 프로그램 설치를 유도하는 체크박스가 나올수 있으니 자세히 확인해 보시면 좋은데요~

원치 않는다면 체크박스를 해제한 후 확인버튼을 누르면 최종적으로 알집 설치가 완료됩니다.

### 3\. 알집 사용 방법

알집 설치가 완료되었다면, 이제 알집을 이용해서 압축을 실행해볼 차례입니다.

업무 또는 파일을 전송하다보면 하나의 파일을 압축하기도 하지만, 폴더 자체를 압축하는 경우가 더욱 많은 것 같습니다.

#### 알집 압축하는 방법

이럴 경우에는 특정한 A폴더에 사진, 동영상, 문서파일을 폴더별로 깔끔하게 정리한 다음 A폴더 화면으로 이동하여 오른쪽 마우스를 클릭하면 알집 압축메뉴가 나오게 됩니다.

\[폴더명\] 또는 \[파일명\]으로 압축하기를 누르면 현재 위치에 특정한 A폴더에 대해서 압축이 시작되고, 잠시후 압축파일이 생성된 것을 확인할 수 있습니다.

어렵게 압축파일 이름을 설정할 필요도 없이 폴더명으로 파일이름이 설정됩니다.

압축 파일을 선택하고 마우스 오른쪽 버튼을 눌러, 팝업창 \[속성\]에서 압축 파일의 용량 및 기타 내용들을 알 수 있는데요!

파일을 압축하는 이유가 예전에는 하드디스크 저장공간을 확보하기 위한 이유가 많았지만, 요즘은 저장용량 확보보다는 정리차원에서 분산된 파일을 하나로 묶어서 저장하거나 이메일로 보내기 위해 사용하는 것 같습니다.

#### 알집 압축해제 하는 방법

해제하는 방법은 압축의 역순이라 생각하면 됩니다. 압축해제를 하고자하는 파알의 오른쪽 마우스를 클릭하면 \[파일명\]에 압축 풀기라는 기능이 있습니다. 이것을 클릭하면 압축이 해제되는데요!

파일명을 폴더로 생성한 다음 그 폴더에 압축파일을 해제하는 방법입니다.

상당히 빠르고 편리하게 압축파일을 해제할 수 있기 때문에 많은 분들이 압축해제 시 사용하고 있는 기능입니다.

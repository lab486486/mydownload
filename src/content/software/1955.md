## 알약 삭제 안될때 해결하는 방법

알약 백신은 다 좋은데 신경쓰이게 하는 광고도 많아서 삭제 하고싶을 충동이 들 때가 많습니다.

참다참다 지워버리고 싶다는 분들이 계셔서 Alyac 삭제 안될 때 해결하는 방법에 대해 알려드리도록 하겠습니다.

윈도우10으로 넘어오면서 알약 삭제를 눌러도 삭제가 되지않는 경우가 종종 있는데 초간단 해결하는 방법을 확인하세요!

### 알약 제거하는 순서

1.  제어판으로 이동
2.  프로그램 제거 클릭
3.  알약 검색 후 제거
4.  화면에 보이는 숫자 입력 후 삭제 진행

> 알약 : (주)이스트소프트에서 제작한 바이러스 국산 백신 프로그램

무료 프로그램이다보니 광고가 필연적으로 들어가는데 이러한 광고 때문에 삭제하려는 분들은 4단계 순서대로 하시면 됩니다.

#### 1\. 제어판 이동하는 방법

> ✅ 시작 > 실행 > control 입력

알약을 삭제하기 위해서는 윈도우 제어판으로 이동해야하는데요!

제어판 위치는 시작메뉴에서 들어가는데 만약 찾기 힘들다면 간단한 방법으로 제어판으로 이동해보시기 바랍니다.

왼쪽 아래 윈도우 로고\[시작\] 메뉴를 누른 후 실행을 누릅니다. 그리고 입력창에 control(컨트롤)을 입력하면 제어판으로 바로 이동하는데요!

우리나라에서는 제어판이라 불리지만, 미국에서는 컨트롤 메뉴로 불리기 때문입니다.

#### 2\. 알약 보안코드 입력 후 제거

> ✅ 알약 보안코드 입력 후 확인 > 삭제 완료

이렇게 제어판에 접속했다면 프로그램 제거 메뉴로 이동하여 알약을 찾도록 합니다.

알약을 찾은 후 알약 제거를 누르면 ‘~~변경하겠습니까?’라는 확인창이 뜨는데 여기서 확인을 누르고 삭제를 누릅니다.

이때 알약 자체 보안 확인창이 나오는데요!

알약의 경우 컴퓨터의 보안과 직접적인 연관이 있는 백신프로그램이다보니 해킹프로그램에 의해 삭제될 위험을 갖고 있어서 이러한 사용자에 의한 직접적인 보안코드 입력을 통해 삭제를 진행하고 있습니다.

화면에 보이는 숫자를 입력하고 확인을 누르면 깔끔하게 삭제가 완료됩니다.

앱 제거 탭에서 안지워지는 프로그램은 이렇게 제어판의 프로그램 제거 메뉴를 통해 삭제하시면 되고, 다른 프로그램도 이러한 방법을 통해 제거하시기 바랍니다.

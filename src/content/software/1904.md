## 디스코드 다운로드(Windows 한글판)

세계적으로 게임유저들이 가장 많이 사용하는 메신저가 바로 디스코드(Discord)입니다.

코로나 이후 스터디, 취미, 강의 등에 활용되면서 다운로드에 대한 관심이 높아지고 있습니다.

아래에서 디스코드 Windows 한글판 다운로드에 대해 알아보도록 하겠습니다.

### 디스코드 다운로드(한글판) 방법

1.  디스코드 공식 홈페이지 접속
2.  다운로드 메뉴 클릭
3.  운영체제(OS) 선택 : Windows, iOS, Linux, Android
4.  설치파일 다운로드(모바일은 스토어에서 설치)

디스코드를 다운로드 받기 위해서는 개인 자료실, 블로그 보다는 디스코드(Discord) 사이트에서 안전하게 내려받아야 합니다.

출처가 불분명한 사이트에서 파일을 내려받아 설치할 경우 랜섬웨어, 바이러스 등에 감염될 수 있습니다.

디스코드 사이트 주소는 위 링크를 클릭해서 이동하여 운영체제(OS)에 맞는 설치파일을 다운로드 하면 됩니다.

모바일의 경우 안드로이드는 플레이스토어, 아이폰은 앱 스토어에서 설치하면 됩니다.

![디스코드-다운로드-페이지](/uploads/2024/06/디스코드-다운로드031-1024x468.webp)

### 디스코드 설치 컴퓨터 사양

디스코드는 메신저 프로그램답게 고사양, 대용량을 요구하진 않습니다.

윈도우의 경우 Windows7 이상, macOS 10.11(El Capitan) 이상, 안드로이드 5 이상 등 그야말로 최소한의 컴퓨터 사양만 충족하면 원활한 구동이 가능합니다.

### 디스코드 다운로드 및 설치 시 자주하는 질문

#### 질문 : Windows의 파일 이름이 너무 깁니다

답변 : 파일 이름에 대한 문제는 보통 게임의 이름이 긴 경우에 나타납니다.

이 오류를 해결하기 위해서는 게임을 짧은 이름의 경로를 가진 곳에 설치하면 해결가능합니다. 예를 들면 바탕화면 같이 경로가 짧은 곳입니다.

#### 질문 : macOS에서 디스코드 재설치는 어떻게 해야하나요

답변 : 먼저 Discord 프로세서를 종료하고, 2개의 폴더를 삭제합니다.

1.  ~/Library/Application Support/Discord
2.  /Library/Application Support/Discord

삭제한 다음 응용 프로그램 폴더를 열어서 Discord를 휴지통으로 드래그합니다. 마지막으로 휴지통을 비운 후 시스템으르 재시작하면 디스코드를 재설치하기 위한 환경이 완성됩니다.

그리고 디스코드를 다운로드해서 설치하면 됩니다.
